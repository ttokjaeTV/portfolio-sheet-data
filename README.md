# 포트폴리오 관리시트 — 시세 데이터

똑재TV 포트폴리오 관리 시트가 읽어가는 ETF 시세 CSV를 자동 생성한다.

## 왜 만들었나

기존 시트는 국내ETF 현재가를 행마다 `IMPORTXML`로 네이버에서 긁어왔다.
종목이 20개만 넘어도 호출 제한에 걸려 `#N/A`가 무작위로 떴고,
종목명은 `국내상장ETF 종목코드(수기등록필요)` 탭에 수기로 채워야 했다.
그 탭은 2025-05-29 기준에서 멈춰 있었다.

이 레포는 시세 수집을 한 곳으로 모은다.
구독자 시트는 CSV 한 줄만 읽으면 되고, 권한 승인도 스크립트도 필요 없다.

## 구조

```
.github/workflows/update-prices.yml   장중 10분마다 실행
scripts/build_etf_prices.py           마스터 + 네이버 시세 → CSV
data/etf_prices.csv                   산출물 (자동 커밋)
```

## 데이터 출처

| 항목 | 출처 |
|---|---|
| 종목코드·종목명 | `ttokjaeTV/etf-selector` 의 `krx_etf_master.json` |
| 현재가·전일대비·등락률 | 네이버 폴링 API (`polling.finance.naver.com`) |

마스터가 갱신되면 신규 상장 ETF가 자동으로 따라온다.
`ttokjae-etf-selector-updater` 스킬로 마스터를 갱신하는 것이 유일한 수동 작업이다.

## CSV 형식

```
종목코드,종목명,현재가,전일대비,등락률,갱신시각
0184E0,1Q 200채권혼합50액티브,10850,-65,-0.60,2026-08-31 13:46
```

약 1,163행 / 82KB.

## 시트에서 읽는 법

`시세` 탭 A1:

```
=IMPORTDATA("https://ttokjaetv.github.io/포트폴리오-관리시트/data/etf_prices.csv")
```

> 실제 주소는 GitHub 레포명에 맞춰 수정할 것.
> 한글 레포명은 URL 인코딩 문제가 있으니 영문 레포명(`portfolio-sheet-data` 등)을 권장.

**A열은 반드시 일반 텍스트 서식으로 지정.**
안 하면 `0184E0` 같은 코드가 지수 표기로 해석돼 `184`로 깨진다.

자세한 시트 수식은 `docs/시트_적용가이드.md` 참고.

## 로컬 실행

```bash
python scripts/build_etf_prices.py
```

## 운영 주의사항

- 네이버 비공식 API라 구조 변경 시 워크플로가 실패한다. Actions 실패 알림을 켜둘 것.
- 시세 누락이 과반이면 스크립트가 종료 코드 1로 죽는다. 깨진 CSV 배포 방지용.
- 마지막 성공분 CSV가 레포에 남으므로 한 번 실패해도 구독자 시트는 즉시 깨지지 않는다.
- `IMPORTDATA`는 구글 쪽 캐시가 있어 시트 반영이 몇 분 늦을 수 있다.
