# 포트폴리오 관리 시트 — 국내ETF CSV 전환 가이드

대상 시트: `(원본)똑재_포트폴리오 관리 시트_V1.9`

## 1. GitHub 레포 준비

이 폴더를 그대로 새 레포로 올린다. **레포명은 영문**으로 할 것
(한글 레포명은 Pages URL 인코딩 문제가 생긴다). 예: `portfolio-sheet-data`

Settings → Pages → Source: `main` / `/ (root)`

배포 후 CSV 주소:

```
https://ttokjaetv.github.io/portfolio-sheet-data/data/etf_prices.csv
```

Actions 첫 실행은 **수동(workflow_dispatch)** 으로 돌려 CSV가 생성되는지 확인한다.

## 2. CSV 형식

```
종목코드,종목명,현재가,전일대비,등락률,갱신시각
0184E0,1Q 200채권혼합50액티브,10850,-65,-0.60,2026-08-31 13:46
```

1,163종목 / 82KB. 마스터(`krx_etf_master.json`)가 갱신되면 자동 반영된다.

## 3. 시트 작업

### (1) `시세` 탭 추가 (숨김 처리)

A1에 이것 하나만:

```
=IMPORTDATA("https://ttokjaetv.github.io/portfolio-sheet-data/data/etf_prices.csv")
```

A열=종목코드, B열=종목명, C열=현재가, D열=전일대비, E열=등락률, F열=갱신시각.

**중요:** A열을 미리 **일반 텍스트** 서식으로 지정할 것.
안 하면 `0184E0`이 지수 표기로 읽혀 `184`로 깨진다.

### (2) 현재가 수식 교체 (I21부터)

```
=IF($D21="","",
 IFS(
   $D21="예수금", $G21,
   $D21="달러 예수금", VALUE(SUBSTITUTE($G21,"$",""))*$G$5,
   NOT(ISNA(MATCH($D21,시세!$A:$A,0))), VLOOKUP($D21,시세!$A:$C,3,FALSE),
   NOT(ISNA(VLOOKUP($D21,'미국개별주식 종목코드'!$B$3:$C,2,FALSE))), GOOGLEFINANCE($D21,"price")*$G$5,
   NOT(ISNA(VLOOKUP($D21,'미국ETF 종목코드'!$B$3:$C,2,FALSE))), GOOGLEFINANCE($D21,"price")*$G$5,
   TRUE, IFERROR(GOOGLEFINANCE($D21,"price"),"")
 ))
```

바뀐 점:

- 국내ETF 분기가 `IMPORTXML` → `VLOOKUP(시세!)` 으로 교체
- 국내ETF를 **첫 번째로** 검사 (가장 흔한 케이스이자 조회가 가장 쌈)
- `TEXT($D21,"000000")` 제거 — 미국 티커와 문자 섞인 ETF 코드를 망가뜨리던 원인
- 중첩 `IF` → `IFS` 로 평탄화
- `GOOGLEFINANCE("USDKRW")` 반복 호출 → 상단 환율 셀 `$G$5` 참조

> `$G$5`는 상단 "원/달러 환율" 셀 주소. 실제 주소를 확인해 맞출 것.

### (3) 종목명 수식 (E21부터)

수기 입력 대신 자동으로:

```
=IF($D21="","",IFERROR(VLOOKUP($D21,시세!$A:$B,2,FALSE),
  IFERROR(VLOOKUP($D21,'국내개별주식 종목코드'!$B$3:$C,2,FALSE),
  IFERROR(VLOOKUP($D21,'미국ETF 종목코드'!$B$3:$C,2,FALSE),
  IFERROR(VLOOKUP($D21,'미국개별주식 종목코드'!$B$3:$C,2,FALSE),"")))))
```

## 6. 운영 주의사항

**IMPORTDATA 캐시** — 구글이 결과를 캐시해 CSV가 갱신돼도 시트 반영이 몇 분 늦다.
자산 현황 확인용이라 문제되지 않지만, 구독자가 "값이 안 바뀐다"고 물을 수 있으니
공지사항 탭에 한 줄 적어두는 걸 권한다.

**장 마감 후** — 마지막 실행(16:40 KST) 값이 다음 개장까지 유지된다.

**네이버 API 의존** — 비공식 API라 구조가 바뀌면 워크플로가 실패한다.
Actions 실패 알림을 켜둘 것. CSV는 마지막 성공분이 레포에 남으므로
한 번 실패해도 구독자 시트가 즉시 깨지지는 않는다.
