# 가격·배당 이력 (`data/history/`)

백테스트 계산기용 원자료. 오늘 시세만 있는 `etf_prices.csv`·`kr_stocks.csv`·`us_prices.csv`와
같은 유니버스를 상장 초기까지 거슬러 받는다. 계산기 쪽 가공(총수익률·적립 시뮬레이션)은
아직 정하지 않았고, 이 폴더는 **가공하지 않은 깨끗한 원자료**만 둔다.

## 값의 성격 — 계산기 만들 때 반드시 볼 것

- ★★ **네이버 국내 ETF 가격(`kr_etf/`, `kr_etf_daily/`)은 분배금까지 소급 보정된 값이다.**
  KODEX 200 2014-12: 네이버 19,621 = 야후 수정종가 19,654, 실제 종가는 24,670 (2026-10 실측).
  즉 이 가격만으로 이미 '분배금 재투자' 수익률이 나온다. **여기에 분배금을 또 더하면 이중 계산이다.**
  종목별 판정은 `kr_etf_basis.csv` (KRX 실제 종가 대비, 분배금보정 806 · 구분없음 352 · 판정불가 18).
- 분배금을 현금으로 받는 계산(월 생활비 등)에는 **KRX 실제 종가 `kr_etf_krx/{코드}.csv`**와
  `kr_etf_distributions.csv`를 쓴다.
- ★ 야후 국내 ETF `close` 는 쓰지 않는다. 일부 달에 분배금 보정값이 섞여 KRX와 월말 17%가 어긋났다
  (ACE 레버리지 2023-07: KRX 7,060 vs 야후 6,970 = 네이버 보정값). 그래서 `kr_etf_raw/`는 지웠다.
- **국내 개별주식·미국 가격은 분할·병합만 보정된 종가다. 배당은 반영되지 않는다.**
  삼성전자(2018 50:1)·SCHD(2024 3:1) 실측으로 보정 확인. 총수익률은 배당 파일과 합쳐 직접 계산한다.
  검산: 2014-12→2024-12 연평균 총수익률 SPY 13.0%·SCHD 11.0%·QQQ 18.3% (공개 수치와 일치).
- **국내 배당금(세이브로)은 '당시 1주' 기준이다.** 가격은 분할 보정값이라 단위가 다르다.
  삼성전자 2017 배당 42,500원 vs 보정 주가 39,460원. `kr_splits.csv`로 이후 분할 비율만큼 나눠 맞춘다.
  ETF는 분할이 드물지만 분배율이 비정상적으로 크면 같은 문제를 의심한다.
- **미국 배당(야후)은 이미 분할 보정돼 있다.** 가격과 같은 단위라 그대로 쓴다.
  월봉 간격으로 받아서 날짜는 월 단위만 남는다(배당락 월).
- **월봉의 '월'은 그 달 마지막 거래일 종가.** 이번 달 행은 장중 값이라 다음 갱신 때 덮인다.
- **지금 상장된 종목만 있다.** 상장폐지 종목이 빠지는 생존편향이 있다(특히 개별주식).
- 국내 주식 분할 표에는 무상증자·유상증자 권리락 조정(예: `1.05:1`)도 섞여 있다.
  큰 분할·병합 2,232건 중 네이버 가격이 보정 안 된 것으로 의심되는 건 50건(`quality_flags.csv` 의 `split_raw`).
- 국내 주식 1990년대 데이터에는 값이 튀었다 돌아오는 오류가 있다(26종목, `flicker`).
  월간 5배·80% 변동(`jump`)도 1990~1999년에 몰려 있다. 계산기는 2000년 이후로 자르는 게 안전하다.
- ★★ 야후 `range=max`는 쓰지 않는다. 오래된 종목은 3개월봉, 상장 짧은 종목은 **주봉**으로 말없이 바꿔 보내
  월말 종가가 1~2% 틀어졌다(JEPI 2020-08 52.95 ← 실제 54.19). `period1=0` 으로 요청하면 전부 월봉이고,
  응답 간격이 월봉이 아니면 오류로 처리한다. 2026-10-16 미국 전 종목을 이 방식으로 다시 받았다.

## 출처를 이렇게 나눈 이유

- 네이버 해외 차트는 **2010-07 이전을 주지 않는다**(SPY·KO·AAPL 모두 2010-07 시작, 2026-10 실측).
  2008 금융위기 구간이 필요해서 미국은 야후를 주 소스로 쓴다.
- 네이버 국내 차트는 1990년부터 준다. 일봉도 한 번에 전 기간이 온다(KODEX 200 5,923일).
- stockanalysis(미국 배당 주 소스)는 Claude 샌드박스에서 403. 야후는 열린다.
- 세이브로는 긴 페이징 도중 연결을 끊는다(Errno 104). 분기 단위로 잘라 재시도하고 캐시한다.

## 스크립트

```bash
python scripts/build_price_history.py kr_etf      # 일봉+월봉, 약 11분
python scripts/build_price_history.py kr_stock    # 월봉, 약 23분
python scripts/build_yahoo_history.py us          # 월봉+배당+분할, 약 27분
python scripts/build_yahoo_history.py kr_split    # 분할 이력, 약 6분
python scripts/build_krx_history.py etf stock     # KRX 월말 실제 종가 — 로그인 필요, Actions 에서 실행
python scripts/build_dividend_history.py etf      # 세이브로 분배금 전체
python scripts/build_dividend_history.py stock    # 세이브로 배당 전체
```

- 가격 스크립트는 **증분**이다. 파일이 있으면 마지막 2개월부터 다시 받아 합친다. `FULL=1`이면 전체.
- 오늘 이미 받은 종목은 건너뛰므로 끊겨도 다시 실행하면 이어 받는다. `LIMIT=N`으로 나눠 돌릴 수 있다.
- 야후·세이브로 원본 캐시는 `.cache/`(커밋 안 함)에 남는다.
- 아직 자동 갱신 워크플로는 없다. 계산기 방식을 정한 뒤 붙인다.

## KRX 월말 시세 (실제 종가·NAV·기초지수)

`scripts/build_krx_history.py etf|stock` · 워크플로 `KRX 월말 이력 수집` (수동 실행)

| 경로 | 내용 |
|---|---|
| `krx_etf_month/{YYYY-MM}.csv` | 그달 마지막 거래일 전종목 스냅숏 — 상장폐지 ETF 포함 |
| `kr_etf_krx/{코드}.csv` | 종목별 `월,기준일,종가,NAV,기초지수,순자산총액` |
| `kr_etf_krx_list.csv` | 종목별 이름·첫월·마지막월·현재상장 여부 |

- 거래소 원본 **실제 종가**라 분배금 보정이 없다. 네이버(분배금 보정)의 빈틈을 메운다.
- 2026-10-15 첫 실행: 289개월 · 1,447종목(상장폐지·이름변경 271) · 빈 달 0 · 약 10분.
  검산 KODEX 200 2014-12 종가 24,670 · NAV 24,716.90 · 기초지수 244.05.
- 그날 상장된 전 종목을 주므로 지금은 없는 ETF도 남는다 — 생존편향을 줄일 수 있다.
- 로그인이 필요해 Actions 의 `KRX_ID`·`KRX_PW` Secrets 로 돈다. 계정 값은 로그에 남기지 않는다.
- KRX 에 ETF 분배금은 없다(분배금은 세이브로).

  연속 수익률을 볼 때는 네이버 `kr_stock/`(분할 보정)을 쓰거나 상장주식수 변화·`kr_splits.csv`로 보정한다.

  같은 단위의 배당수익률 계산.
- 2026-10-15 첫 실행: 1995-05~ 378개월 · 5,459종목(상장폐지·이름변경 2,616) · 빈 달 0 · 약 24분.
  현재 상장 2,843종목은 전부 포함. 검산 삼성전자 2017-12 실제 종가 2,548,000 = 네이버 50,960 × 50(분할 비율).
- 네이버 `kr_stock/`과 월말 대조(2024년 이후) 불일치 20%의 대부분은 이후 분할·병합으로 네이버가 소급
  보정한 것(비율 0.1·0.2·0.5·2.0)이라 정상이다.
- 다만 **최근 두 달(2026-09·10)은 비율 1% 안팎 불일치가 1,800~2,000종목**에 몰려 있다. ETF는 일치한다.
  넥스트레이드(NXT) 애프터마켓까지 합친 통합 시세를 네이버가 최근 구간에 쓰는 것으로 추정한다(미확인).

  - AVGO: 2018-03·06 분기배당을 2배(0.35)로 기록 → 0.175로 교체

  - TLT·SHY·BND 12월: 정기분+연말분 두 번 지급을 야후는 합쳐 있고 나스닥 공식 이력은 한 건만 있다
  - 소수점 셋째 자리 반올림 차이(±2~3%, 0.018달러 수준)
- **stockanalysis 대조의 '불일치' 대부분은 대조 창 끝(첫 달·마지막 달) 잘림**이다. 실제 오류는 DGRW 2건뿐.

## 백테스트 계산기 (`backtest/`, `data/bt/`)

- 화면: `backtest/index.html` (빌드 결과) ← `backtest/src/` (template.html · base.css(배당 재투자 계산기와 같은 디자인) · extra.css · engine.js · app.js · build.py · test.js)
